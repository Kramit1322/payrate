# 💳 PayRate

### UPI Charges & MDR Calculator for India

**Simple. Transparent. Free.**

PayRate is an independent informational tool designed to help users understand and calculate applicable UPI merchant charges (MDR).

🌐 **Live Website:** https://payrate.lovable.app/

---

## 🚀 Features

- 🧮 UPI MDR calculation
- 📲 P2P and P2M transaction support
- 🏪 Merchant category-based calculation
- 💰 Merchant MDR breakdown
- ₹0 customer charge display
- 📊 Clear calculation summary
- 📱 Mobile-friendly interface
- 🆓 Free to use
- 🔐 No login required

---

## 📋 Current Calculation Framework

PayRate considers the applicable transaction type, amount and merchant category when calculating MDR.

Examples include:

| Transaction | Amount | Example MDR |
|---|---:|---:|
| P2P | ₹5,000 | ₹0 |
| P2M | ₹2,000 | ₹0 |
| P2M | ₹2,001 | 0.40% |
| P2M | ₹5,000 | ₹20 |
| P2M | ₹75,000+ | Up to ₹300 cap |

The calculator also handles applicable special merchant categories and exemptions.

> **Note:** Payment rules and charges can change. Always verify the latest applicable rules with official sources.

Understanding payment charges shouldn't require complicated calculations.
